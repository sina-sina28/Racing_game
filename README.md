## Organisation du code (MVC)



\- model/ : données et règles du jeu (voiture, circuit, cases)

\- view/ : affichage avec pygame

\- controller/ : clavier et boucle de jeu

\- constants.py : constantes partagées

\- main.py : point d'entrée du jeu



## Commandes

\- Joueur 1 : Z avancer, S reculer, Q gauche, D droite, Espace objet

\- Joueur 2 : flèches, Entrée objet
